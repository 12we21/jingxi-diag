## 三、一版成立（`wait`，0–10.52 秒）

按龙龙的艺术指导重做。核心命题：**关系留下的痕迹**。

| 图 | 时间 | 内容 |
|---|---|---|
| `shots/win_01_wait_0850.jpg` | 8.5s | 13 行旧对话的磷光残影，最上面一行是 `我叫你鲸鲸好么` |
| `shots/win_02_wait_1000.jpg` | 10.0s | 最旧那行正在褪去，光标还在闪 |

**做了什么：**

- **只有一次运镜**：极慢推近 z=1.00 → 1.16，全程 10.5 秒
- **内部变化**：
  - 光标闪烁（0.85s 周期，边缘 0.06s 软化）
  - 歌词 `Zero... zero...` 逐字打出
  - 13 行残影按不同时间浮现
  - 最旧的一行（中文）在最后 2 秒淡出
  - 扫描线极缓慢向下滚动
- **关系的证据**：那 13 行对话不是装饰。它们是"这个屏幕被用过很多次"的物证。
  最上面那行是 `我叫你鲸鲸好么`，下面回 `> 好`。**一闪就没了，观众可能来不及读完，但那正是重点。**

**逐条对照龙龙的验收清单：**

- [x] 服务于歌词和情绪
- [x] 明确的视觉主体（一列旧对话 + 一个光标）
- [x] 必要的留白（右侧三分之二，但不是空的——有磷光和扫描线）
- [x] 运动有意义（一次推近，10.5 秒）
- [x] 留下关系的证据（13 行旧对话）
- [x] 与全片叙事一致（这是"第一次打开"之前的状态）
